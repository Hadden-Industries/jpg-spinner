# Packaged-app placeholder assets

These PNG files are the unmodified placeholder assets from Microsoft's
packaged C++/WinRT Windows App SDK project template at commit
[`1e3ee1021a53d7ff0d633a1f2eef47c3e765b78f`](https://github.com/microsoft/WindowsAppSDK/tree/1e3ee1021a53d7ff0d633a1f2eef47c3e765b78f/dev/Templates/Source/ProjectTemplates/Desktop/CppWinRT/SingleProjectPackagedApp/Assets).
They retain the upstream repository's MIT license. Product artwork replaces
them during the later presentation/release work; keeping the original files
here makes the Task 2 scaffold buildable without inventing interim branding.
